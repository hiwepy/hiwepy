### 💡 相信的

- AI Agent 的瓶颈不在模型能力，在工程化 —— 可复用的 Skills、可靠的记忆、可编排的协作协议才是从 demo 走向生产的关键
- 好的架构来自对业务痛点的深刻理解，而非对技术热点的追逐
- 技术管理者的价值不在"管人"，在降低团队认知负载、提高决策质量
- 开源是技术人最好的简历
